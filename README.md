# Tokenmonk

Mindful about your tokens. Or not.

A small tray widget for macOS and Windows that shows your live Claude Code
token usage and how much of your subscription limit is left, with a bit of
gamification on top.

Status: early development, nothing to install yet.

## Privacy

Tokenmonk reads Claude Code's local logs and never modifies them. Nothing
leaves your machine except the limit lookup to Anthropic and the update check.
